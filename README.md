Summary
- Personal portfolio & case studies for Vishnu Prakash — Power BI dashboards, analytics projects and ML PoCs. Built to showcase business impact, dashboards, and end-to-end analytics solutions.

Quick links
- Live site: https://infinitynestdataanalytics.com

Project architecture
- Content (markdown) + static assets -> GitHub Pages build -> Deployed site (Pages / Vercel). Source of truth: this repository.

Highlights for recruiters
- Clean case studies with context, problem, impact metrics and demo GIFs.
- Links to interactive Power BI reports and sample datasets.
- Concise skill badges: Power BI, SQL, Python, ML, Data Modeling.

Installation & local preview
1. Clone
   git clone https://github.com/vishnu007prakash/Portfolio-Site.git
2. Preview (if using simple static server)
   python -m http.server 8000 --directory .
3. For a static site generator (if applicable) follow generator README in /docs.

Usage / How to review
- Case studies: open the case-study markdown files in /docs/case-studies
- Dashboard demos: link to /assets or to Release assets for .pbix files
